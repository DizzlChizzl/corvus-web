# Corvus Web

Frontend-Lab für Corvus-Webmodule.

## Aktueller Stand

Build 0.1 enthält eine mobile Standalone-Demo für das Royal Family Goose Goose Duck Bingo.

- 5x5 Bingo-Karte
- neue Karte generieren
- Felder antippen
- Flip-Animation
- Rückseite mit `<f3` als Royal-Family-Mark-Platzhalter

## Ziel

Dieses Repository dient als schnelle Testumgebung, bevor Module später in WordPress/IONOS integriert werden.

Geplante Module:

- GGD Bingo
- GGD Knowledge
- GGD Maps
- Royal Family Tools
- weitere Corvus-Webmodule
